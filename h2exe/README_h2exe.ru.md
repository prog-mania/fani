## Описание
Программа h2exe.exe служит для преобразования файлов html+js в exe.
Команда запуска:
*  h2exe.exe xo.html
В результате будет создан файл xo.exe, который будет работать 
как xo.html в браузере, но без браузера.

## Подробнее
Программа h2exe.exe использует программу mshta.exe, входящую в windows,
поэтому js там старый без canvas, webGL, mp3 и т.п.
Зато есть доступ к системе через activX и сервер не нужен,
поэтому exe файлы могут быть очень маленькие, например:
игра крестики-нолики xo.exe  17 кбайт.
