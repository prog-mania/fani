## Описание
Программа server.exe служит для борьбы с запретами браузера при программирования на javaScript.
С ней javaScript может всё, и даже работать как exe файл. 
А также:
если указать в параметре запуска какой-нибудь файл html, она его покажет,
используя установленный в windows браузер Chrome.
Если потом нажать кнопку "Создать EXE", будет создан файл exe,
который будет показывать этот html, используя все нужные файлы из самого себя.
И ещё может говорить и создавать файлы wav с разными голосами из текста, используя SAPI.

## Подробнее
Программа server написана на Delphi 7. Исходные тексты в этой папке. Файл проекта server.dpr.
Также есть уже скомпилированный и сжатый UPX файл server.exe.

Если в файл exe добавлены файлы кнопкой "Создать EXE", то их можно извлечь: <br>
переключиться на сервер alt+Tab,       <br>
вызвать его системное меню alt+пробел, <br>
вытащить его из-за правого края        <br>
и нажать кнопку "Extract from exe".    <br>

Возможности, вызываемые из браузера, описаны в файле serverForm.pas в процедуре
TForm1.IdHTTPServer1CommandGet.
Примеры их использования из JS в файле fani.js.

Примеры файлов exe, созданных программой server.exe:
fani.exe, model.exe, model-small.exe.
